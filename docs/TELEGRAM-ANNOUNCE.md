# Объявление об обновлении в Telegram-канале

После каждого выпуска `promote-production.yml` присылает в канал игры сообщение от бота.
Канал игры: https://t.me/diarydevelopment (бот — администратор).

## Обязательная структура постов об обновлениях

1. **Динамический заголовок обновления** (разнообразный тон без сухих шаблонов):
   `🧩 Tiletopia 1.0.X — вышло обновление!` / `🚀 Tiletopia 1.0.X уже в игре!` и др.
2. **✨ Что нового** — только новшества для игроков, оформленные красивой цитатой `<blockquote>...</blockquote>`.
3. **🔧 Что изменилось** — улучшения, доработки и перемещения элементов.
4. **🧹 Что убрано** — удалённые элементы и очистка интерфейса (например, счётчики онлайна).
5. **🎮 3 способа играть** (всегда в каждом посте):
   - 📱 **Android:** APK-приложение с автообновлением
   - 🌐 **Все устройства (ПК, iOS, планшеты):** сайт в браузере
   - ✈️ **Telegram:** мини-приложение прямо в боте
6. **📊 Вопрос / Опрос для игроков и тестеров** — вовлекающий вопрос о нововведениях для поддержания активности и сбора статистики от игроков и тестеров в комментариях к посту (а также поддержка нативного `sendPoll`).

> [!NOTE]
> Внутренние технические задачи (экспорт спрайтов плиток, приватные стейджинги для дизайнера, пин-коды, markdown-отчеты) фильтруются автоматически и **никогда не публикуются в канале для игроков**.

## Настройка (один раз, делает владелец)
1. Репозиторий → Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN` — токен бота от BotFather;
   - `TELEGRAM_CHAT_ID` — необязательно: по умолчанию используется канал `@diarydevelopment` (https://t.me/diarydevelopment). Нужен только если канал сменится (`@имя` или числовой id `-100…`).
2. Бот должен быть администратором канала с правом публикации сообщений (уже сделано).
3. **Токен никогда не пишется в репозиторий, переписку и логи.** Если токен попал в чат или файл — выпустите новый: BotFather → `/revoke` для бота, затем обновите секрет.

Скрипт: `scripts/telegram-notify.py`, тест: `tests/telegram-notify.test.cjs`.
