## Где что лежит

- Боевой код: ветка `main`. Каждый пуш в `main` или `dev/**` собирает тестовое приложение (релиз `staging-latest`).
  **Тестовая сборка — это последний пуш в любую из этих веток**, поэтому пушить в `dev/**` устаревший код нельзя:
  он заменит тестовую сборку. Перед пушем в ветку `dev/*` влейте в неё `origin/main`.
  `dev/test-features` держите равной `main`: `git push -f origin origin/main:refs/heads/dev/test-features`
  (не пушьте локальный `main`, он может быть устаревшим).
- Выпуск в боевую: `gh workflow run promote-production.yml --ref main -f announce=false`.
  Пост в Telegram только по просьбе владельца (`announce=true` или `telegram-announce.yml -f tag=vNNN`).
- `release-notes.md` перед каждым выпуском переписывается заново: **только новое с прошлого выпуска**, без повторов.
- Последний выпуск этой сессии: v272 (или следующий номер), коммит «quests and history redesigned...».
