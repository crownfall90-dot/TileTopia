# 3D-плитки и 2D-спрайты из одного источника

## Источник правды
`assets/tiles3d/tiles.json` строится из `TYPES` (`src/engine/tiles.js`) командой `node scripts/gen-tile-defs.mjs`
(`--check` — проверка, что файл не устарел). Движок не трогаем. 37 плиток: 29 обычных + 8 редких `x*`.
Для каждой: `id`, стороны N E S W, число в стопке, город (какие стороны), дороги и реки (пары сторон или тупик
к центру), озеро, конец дороги (`boulders` / `mine` / `cliff`), список особенностей.

## Как выглядит
- **Верх плитки — та самая грань, что рисует игра** (`src/render/art.js`, `drawTile`; экспорт в 576 px —
  `node scripts/export-faces.mjs` → `assets/tiles3d/faces/<id>.jpg`): извилистые реки, озёра с кувшинками,
  изогнутые дороги, плотная застройка города — 3D-плитка читается как плитка на столе.
- **Водопады**: где река уходит за край, по боку плитки бежит вода с пеной внизу, как `.sd.fall` в игре. Каждый —
  отдельный узел GLB (`fall_N`, `fall_E`, `fall_S`, `fall_W`): игра показывает его только там, где у реки нет соседа.
- **На грани — объёмные версии спрайтов игры**: 4 дома с фахверком, окнами, дверью и трубой; круглая башня
  с зубцами, красной конической крышей и флажком (как на иконке и баннере); ель, яблоня с яблоками, берёза,
  тополь, куст с ягодами, камень, стог, валуны, шахта. Плюс низкая стена с зубцами по дуге города и каменный
  арочный мост с настилом. Расстановка — по правилам `generateDecorItems` (`src/game/world.js`).
- Свет как на иконке и баннере: низкое тёплое солнце, холодная подсветка неба, мягкие тени.

## Генератор
```bash
python tools/blender_generators/tint_textures.py              # атлас деталей (после правки палитры)
blender -b -P tools/blender_generators/generate_tiles.py -- --set classic [--ids rS,capRS,wBr] [--views top,iso] [--props]
```
- Плитка 2×2, начало координат — центр основания, Z вверх в Blender (в GLB по стандарту glTF — Y вверх).
- Ничего не выступает за край (что вылезло — срезается ровно по краю), грань стыкуется как в игре.
- Текстуры деталей: Poly Haven (CC0), `assets/tiles3d/textures/src`, тонированы в цвета спрайтов игры.

## Оптимизация для телефонов
- **2 материала на плитку**: `TileFace` (UV 0..1 — игра подставляет грань, которую и так рисует, новых
  картинок не нужно) и `TileAtlas` (все детали в одном атласе `textures/atlas.jpg`, 1024², ~170 КБ).
- GLB без картинок и без нормалей (плоское затенение, three.js считает сам): пробные 22–36 КБ.
- Треугольники: дорога 416, город 604, мост 706 (бюджет 5 000). Детали отдельно — `assets/tiles3d/props/*.glb`
  (дом 34, башня 180, ель 58, яблоня 180): игра может расставлять их сама через `InstancedMesh`, сохраняя
  случайную расстановку на каждой карте, — это и дешевле, и разнообразнее.
- «Экономный» режим: только цвет вершин (`vertexColors`, без атласа); «красивый»: атлас. Тени — не в реальном времени.
- Поворот в игре (r четвертей по часовой) = поворот вокруг вертикали на −90°·r.

## Выход
- `assets/tiles3d/classic/<id>.glb`, отчёт `_report.json` (треугольники, размер).
- `assets/tiles3d/renders/classic/top/tile_<id>.png` — вид сверху 512×512, кадр ровно по плитке (как старые спрайты).
- `assets/tiles3d/renders/classic/iso/tile_<id>.png` — изометрия 512×512, прозрачный фон, один ракурс и свет.
- Старый плоский экспорт `assets/tiles/tile_*.png` удалён: он отставал от игры (прямые реки). Источник граней —
  только `art.js` через `scripts/export-faces.mjs`.
