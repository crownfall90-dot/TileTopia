# Публикация в Google Play

Всё для страницы в магазине лежит в репозитории, файл приложения собирается автоматически.

## Что загружать

| Что | Где взять |
| --- | --- |
| Файл приложения (AAB) | GitHub → Releases → последний релиз → `Tiletopia-1.0.N-google-play.aab` |
| Значок 512×512 | `store/icon-512.png` |
| Баннер 1024×500 | `store/feature-1024x500.png` |
| Скриншоты телефона 1080×1920 | `store/screenshots/` |
| Политика конфиденциальности | https://crownfall90-dot.github.io/TileTopia/privacy.html (English: …/privacy-en.html) |
| Пользовательское соглашение | https://crownfall90-dot.github.io/TileTopia/terms.html (English: …/terms-en.html) |
| Сторонние материалы | https://crownfall90-dot.github.io/TileTopia/licenses.html |
| Страница удаления аккаунта | https://crownfall90-dot.github.io/TileTopia/delete-account.html |
| Ответы для «Безопасности данных» | `docs/product/GOOGLE-PLAY-DATA-SAFETY.md` |

Скриншоты и графика пересобираются командой `node scripts/store-assets.js` после `./scripts/wrap-web.sh`.

## Шаги в Play Console

1. Заведите аккаунт разработчика: https://play.google.com/console (разовый взнос 25 $).
2. **Создать приложение** → название «Tiletopia», язык русский, «Игра», «Бесплатное».
3. **Тестирование → Закрытое тестирование** → создайте выпуск, загрузите `.aab`, вставьте текст из `release-notes.md`.
   У новых личных аккаунтов Google требует закрытый тест: минимум 12 тестировщиков в течение 14 дней. Только после этого откроется доступ к рабочей версии.
4. При первой загрузке согласитесь на **подписание приложений в Google Play**. Ключ `app/release.keystore` из репозитория станет ключом загрузки.
5. Заполните **Контент приложения** (ответы ниже) и **Основную страницу** (тексты ниже).
6. После теста: **Рабочая версия → Создать выпуск** → тот же `.aab` → отправить на проверку.

Каждая следующая версия: слить изменения в `main` → GitHub соберёт новый `.aab` → загрузить его в новый выпуск. Игроки получат окно «Доступно обновление» от Google Play, а после обновления игра покажет «Что нового».

## Тексты страницы

**Название (до 30 символов):** Tiletopia: строй миры

**Краткое описание (до 80 символов):**
Стройте города, дороги и монастыри из общей стопки карт с друзьями онлайн

**Полное описание:**

Tiletopia — настольная игра о строительстве мира из карт для 2–5 игроков.

Игроки по очереди тянут карту из общей стопки и пристраивают её к полю: продолжают дороги, расширяют города, огибают реки и окружают монастыри. Ставьте свою фигурку на город, дорогу или монастырь — объект станет вашим, и когда его достроят, очки получите вы. Даже если последнюю карту положил соперник.

Когда стопка закончится, побеждает тот, у кого больше очков.

• Поле в 3D: двигайте его пальцем, приближайте щипком, меняйте угол обзора
• Онлайн с друзьями: создайте комнату и отправьте код, каждый играет со своего телефона
• За одним телефоном: передавайте телефон по кругу
• Боты-соперники для тренировки, в том числе без интернета
• Свои правила: размер стопки, реки, число фигурок, время на ход
• Подсчёт очков: дорога — 1 за карту, город — 2 за карту, монастырь — 9
• Золото за победы: покупайте фигурки — крестьянина, монаха, рыцаря, лучника, короля
• Партия сохраняется: закрыли игру — продолжите с того же хода

Скоро новые локации: мегаполис, снежная Сибирь и джунгли.

Без рекламы и покупок за деньги.

**Категория:** Игры → Настольные игры. **Теги:** настольная игра, стратегия, мультиплеер.

## Ответы для «Контента приложения»

- **Политика конфиденциальности:** ссылка из таблицы выше.
- **Реклама:** нет. **Покупки в приложении:** нет (золото только игровое, за деньги не продаётся).
- **Доступ к приложению:** все функции доступны без входа. Вход по почте или через Google — только чтобы сохранить профиль и играть с друзьями.
- **Возрастной рейтинг (анкета IARC):** категория «Игры». Насилия, страха, азартных игр, нецензурной лексики, наркотиков нет. Общение между игроками — нет (в комнате видны только имена). Покупок нет. Ожидаемый результат: 3+ / PEGI 3.
- **Целевая аудитория:** 13 лет и старше. Если выбрать младше 13, приложение попадёт под требования программы «Для всей семьи» и проверка станет строже.
- **Разрешения:** уведомления — только о выходе новой версии игры.
- **Безопасность данных:** отвечать строго по `docs/product/GOOGLE-PLAY-DATA-SAFETY.md` (там учтены почта, Firebase UID, Analytics и Crashlytics). Анкета, в которой не отмечены отчёты о сбоях и почта, не совпадёт с политикой конфиденциальности и с тем, что Google видит в SDK, — это частая причина отклонения.

## Push о новой версии для игроков из Google Play

После того как новая версия прошла проверку и вышла в Google Play: GitHub → **Actions → Send update push → Run workflow** → выберите `play` и введите номер версии (например, 107). Игроки версии из Google Play получат уведомление. Игроки версии с GitHub получают его автоматически при каждом релизе.
- **Новостное приложение / COVID / госуслуги:** нет.

## Вход через Google в версии из Google Play

Google Play переподписывает приложение своим ключом (Play App Signing), поэтому у сборки из магазина другой SHA-1, чем у APK с GitHub. Без него вход через Google в версии из Play выдаёт «misconfigured» (вход по почте работает).
После первой загрузки `.aab`: Play Console → **Тестирование и выпуск → Целостность приложения → Подписание приложений** → скопируйте **SHA-1 ключа подписи приложения** (и SHA-1 ключа загрузки) → Firebase → Настройки проекта → приложение `app.crownfall.tiletopia` → «Добавить отпечаток» → затем скачайте обновлённый `google-services.json` в `app/`.

## Подпись и ключ

Сборки подписываются ключом `app/release.keystore` (пароль задаётся секретами `KEYSTORE_PASSWORD` и `KEY_PASSWORD`, иначе используется пароль по умолчанию из `app/build.gradle`). Для Google Play это только ключ загрузки: при подписании через Google Play его можно заменить через поддержку, если он утечёт.
