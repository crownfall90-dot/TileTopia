## 🎨 2. Полный реестр реализованных подсистем (на момент v295)

### 2.1. Плавный свайп разделов в стиле Clash Royale
- Непрерывная горизонтальная лента с точным следованием за пальцем 1:1, физикой кинетической инерции и эластичным сопротивлением на краях.
- Эффект микро-отскока (`bnavPop`) с золотистой подсветкой активной вкладки нижней навигации при смене экранов.

### 2.2. Королевский минималистичный баннер профиля
- Баннер в `#profile` (`.pctop.with-banner`) очищен от нагромождения цифр: на самой иллюстрации отображаются **только** гербовый аватар игрока, сияющий никнейм и аккуратная плашка статуса.
- Уровень игрока, шкала опыта (XP), карточки кубков и наград, баланс тайлов и редких звёзд вынесены под баннер на обсидиановую подложку карточки.
- Новейшие живописные баннеры («Скалистый утёс», «Цитадель», «Пик Дракона», «Королевская гавань») переведены на оплату редкими звёздами (2⭐, 3⭐, 5⭐, 8⭐).

### 2.3. Королевская карточка соперника (`.pl-dialog-v2` / `src/ui/playerCard.js`)
- Полноформатный заголовок с баннером, кинематографичным затемнением, гербовым аватаром, бейджем сетевого статуса (онлайн/офлайн/в игре) и светящимся никнеймом.
- Аккуратный 4-плиточный подиум статистики: Кубки, Победы, Партий, Достижения.
- Быстрые действия: добавить в друзья, скопировать код, пожаловаться.

### 2.4. Интерактивная универсальная примерочная (`openBannerFitting()`)
- Доступна в **Витрине** («Примерить» перед покупкой) и в **«Моих предметах»** (при клике на любой предмет).
- Поддерживает 4 категории: «Баннеры», «Аватарки», «Формы», «Рамки».
- Два режима предварительного просмотра: «В моем профиле» и «В карточке соперника» (то, как вас видят другие игроки).
- Покупка и экипировка прямо из примерочной в один клик.

### 2.5. Перенос электронной почты в Настройки
- Адрес email удален из шапки профиля.
- Размещен в карточке аккаунта в Настройках (`#scr-settings` -> `#acct`) с аккуратной иконкой конверта и статусом привязки.

### 2.6. Кнопка возврата в партию в главном меню
- Если игрок случайно вышел в главное меню или свернул приложение во время партии, в меню появляется крупная пульсирующая золотая кнопка «Вернуться в партию» (`#btnMenuResumeGame`).
- Поддерживает возврат в активную локальную игру, восстановление из сохраненного состояния на устройстве или переподключение к онлайн-комнате.

### 2.7. Новое правило: позднее заселение своих объектов
- Если игрок выложил плитку во время партии, но не выставил на неё фишку тем же ходом, **любым последующим ходом** при выкладывании смежной плитки он может выставить мипла на свой свободный объект (достроенный или ещё недостроенный — например, на ранее выставленный монастырь).
- В движке реализована функция `touchingMine(tiles, meeples, t, p)` в `src/engine/scoring.js`.
- Написаны тесты в `tests/engine-done-mine.test.cjs`.
- Правило детально описано в разделе «Как играть» (`#scr-rules`, вкладки «Основы» и «Фишки»).

### 2.8. Защита партий от прерывания обновлениями (Pending Updates)
- Если во время партии выходит новая версия, игра **никогда не прерывает матч**.
- Диалог обновления откладывается в очередь `pendingUpdate` и показывается только после завершения партии при переходе в главное меню.

### 2.9. Устойчивая Google-авторизация и fallback
- Интеграция с Android Credential Manager и fallback на чистую регистрацию при устаревшем или конфликтующем токене.
- Понятные сообщения об ошибках на русском языке в `classifyAuthError`.

### 2.10. Уникальные чистые релизные примечания
- Файл `release-notes.md` содержит только свежие, не повторяющиеся описания изменений текущей версии.

### 2.11. Архитектурная спецификация перехода на Rust + Wasm
- В файле `docs/HYBRID-RUST-MIGRATION-PROMPT.md` зафиксирована полная мастер-инструкция для следующего этапа: вынос тяжелых математических расчетов (MCTS ИИ-бот, BFS поиск замкнутых графов дорог и городов) в компактный WebAssembly-модуль на Rust.

## 📂 3. Карта ключевых файлов проекта

| Файл / Папка | Описание |
|---|---|
| `web/game.html` | Основная разметка, модальные окна, Canvas-отрисовка, примерочная, возврат в игру. |
| `src/ui/styles.css` | Стили обсидианового стекла, анимации, адаптивная мобильная верстка. |
| `src/engine/` | Ядро игры: `board.js`, `scoring.js` (с `touchingMine`), `tiles.js`, `bots.js`. |
| `src/ui/playerCard.js` | Королевская карточка соперника (`.pl-dialog-v2`). |
| `src/state/avatars.js` | Каталог баннеров, аватарок, форм с ценами в тайлах и звёздах. |
| `src/state/catalog.js` | Каталог фигурок, рамок, сундуков, локаций. |
| `src/ui/shop.js` | Витрина магазина, прилавки, модалки покупки и примерки. |
| `docs/HYBRID-RUST-MIGRATION-PROMPT.md` | Мастер-промпт и ТЗ для гибридного перехода на Rust + WebAssembly. |
| `tools/wrap_web.py` | Упаковщик бандла через Vite в `app/src/main/assets/index.html` и `build/web/index.html`. |
| `app/build.gradle` | Сборка Android APK (`staging` и `production`). |
| `.github/workflows/android.yml` | CI/CD публикации боевых релизов. |
| `.github/workflows/staging.yml` | CI/CD автосборки тестового APK при каждом коммите. |

```powershell
# Запуск юнит-тестов (все 258 тестов обязаны проходить):
npm test
# или:
node --test tests/*.test.cjs

# Пересборка веб-ресурсов для Android и Web:
```
