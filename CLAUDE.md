# Tiletopia — Инструкции для разработчиков и агентов (Claude Opus 5.5 / Antigravity)

> **Статус проекта: АКТИВЕН.** Все 218 unit-тестов проходят успешно (`node --test tests/*.test.cjs`).
> **Текущая боевая версия (Production):** `v261` (APK `app.crownfall.tiletopia`)
> **Тестовая среда (Staging):** отдельное изолированное приложение **«Tiletopia Test»** (`app.crownfall.tiletopia.test`), публикуется в релиз `staging-latest`.
> **Встроенный авто-апдейтер:** работает из коробки в тестовом приложении и обновляет APK без необходимости ручного скачивания из браузера.

## 1. С чего продолжать работу (Next Steps & Hand-off)

1. **Тестовые сборки и авто-обновления:**
   - Workflow `.github/workflows/staging.yml` автоматически увеличивает `versionCode` на единицу больше предыдущей сборки (`PREV_STAGING + 1`, сейчас `263+`).
   - Файл `latest-staging.json` генерируется с `"mandatory": true`, а в `web/game.html` тестовые версии `-test` гарантированно вызывают всплывающий диалог «Вышло обновление ... [Обновить]» сразу при запуске.
   - Пользователю-тестировщику больше **не нужно вручную скачивать APK** при каждом коммите — приложение само предлагает обновиться в один клик.

2. **Главная страница (Меню):**
   - Кнопка **«ИГРАТЬ»** сделана крупной, доминантной (`flex: 1.7`, высота `54px`, шрифт `18px 900`, иконка `22px`, золотой градиент) по сравнению с компактными боковыми кнопками «Задания» и «Режим» (`flex: 0.75`, `42px`).
   - По центру главного экрана расположена карточка **«🏆 Рейтинг игроков»** (показывает текущие кубки и сезон Лиги) + кнопка `🏆` в шапке `mtop`. Клик открывает полноэкранный экран `#scr-rating`.

3. **Нижняя навигация и раздел «Задания и Прогресс»:**
   - В нижней панели `bnav` кнопка «Профиль» заменена на раздел **«🎯 Задания»** (`data-nav="progress"`).
   - Внутри раздела `#scr-progress`:
     - **Дорога прогресса (Progress & Trophy Road):** горизонтальная интерактивная шкала с наградами за уровни и кубки (золото, статус «Следопыт», рамка «Изумруд», фигурка «Магистр», «Золотой сундук», чемпионские кубки) с кнопками «Забрать».
     - **Задания:** ежедневные квесты, недельные цели с «Большим сундуком недели» (+100 золота), достижения и коллекции.
     - Красная точка-индикатор на кнопке «Задания» загорается, если есть доступные к получению квесты или награды на Дороге прогресса.

4. **Профиль игрока (`#scr-profile`):**
   - Вынесен в отдельный экран, открывается при клике на аватар/никнейм игрока в левом верхнем углу меню (`#mprof`).
   - Очищен от квестов и рейтинга: содержит только личную информацию игрока (аватар, ник, статус, уровень с кольцом опыта, рюкзак «🎒 Мои предметы», статистика винрейта, мастерство по режимам, постройки и вход/выход).

5. **Уведомления (тосты):**
   - Плашка уведомлений (`.tile-toast, .note`) смещена вниз (`top: max(64px, ...)`) и уменьшена в размерах, чтобы гарантированно не перекрывать кнопки шапки и верхний интерфейс.
   - Внутриигровой тост `.toast` смещён на `top: 60px` с `pointer-events: none`.

6. **Кнопка «Сыграть с ботами» внизу экранов:**
   - Лишняя кнопка убрана из экрана правил и нигде внизу экранов не дублируется.

## 2. Архитектура проекта и ключевые файлы

| Файл / Директория | Назначение |
|---|---|
| `web/game.html` | Основная разметка, игровые экраны (`#scr-menu`, `#scr-profile`, `#scr-progress`, `#scr-rating`, `#scr-shop`, `#scr-friends`, `#scr-rules`, `#scr-game`), обработчики и UI-логика. |
| `src/ui/styles.css` | Основные стили игры, включая адаптивные стили мобильного приложения, анимации плиток, сундуков, дороги прогресса, навигации. |
| `src/engine/` | Игровой движок плиточной стратегии: правила (`board.js`), генерация плиток (`tiles.js`), подсчёт очков (`scoring.js`), ИИ ботов с 3 уровнями сложности и архетипами (`bots.js`). |
| `src/account/auth.js` | Авторизация, генерация разнообразных мультиязычных никнеймов (геймертаги, тотемы, титулы). |
| `src/state/` | Состояние игры: прогресс, ежедневные и недельные задания (`progress.js`), каталог фигурок, рамок и сундуков (`catalog.js`), сохранение матчей (`save.js`). |
| `src/ui/inbox.js` | Центр уведомлений и наград («Статус Олд», промокоды, подарки). |
| `app/build.gradle` | Сборка Android: флейворы `staging` (`app.crownfall.tiletopia.test`) и `github` / `play` (`app.crownfall.tiletopia`). |
| `app/src/staging/java/.../Updater.java` | Клиент авто-обновления для тестовой версии: проверяет `staging-latest/latest-staging.json` и устанавливает апдейты поверх установленного приложения. |
| `.github/workflows/staging.yml` | Непрерывная сборка тестового APK при каждом пуше в `main` и `dev/**` с авто-инкрементом versionCode и публикацией в релиз `staging-latest`. |
| `.github/workflows/promote-production.yml` | Публикация боевого релиза в один клик. |
| `tools/founder-admin.html` | Панель основателя: мониторинг тестовой сборки, список невыпущенных коммитов (`prodTag...main`), управление релизами. |
