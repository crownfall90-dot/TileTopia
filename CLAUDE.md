# Инструкция для Claude: текущее состояние игры и правила работы

Этот документ фиксирует актуальное состояние кодовой базы Tiletopia, последние выполненные фичи и контекст для Claude, чтобы продолжать разработку без потерь контекста.

---

## 1. Что было сделано и актуально в игре

1. **Главная страница (`#scr-menu`):**
   - Кнопка «ИГРАТЬ» сделана доминантной и заметно крупнее остальных (`flex: 1.7` vs `0.75`, высота `54px`, крупный шрифт `18px 900`, иконка 22px, золотое 3D-свечение).
   - Рейтинг игроков перенесён из профиля на главную страницу:
     - Карточка `#btnMenuRatingCard` с отображением текущих кубков игрока и тегом сезона (напр. «Сезон 1 · До конца 18 дн.»).
     - Кнопка быстрого перехода к Рейтингу `🏆` в верхней панели (`#btnMenuRating`).
     - Выделенный экран `#scr-rating` с пьедесталом лидеров (Топ-3: 👑, 🥈, 🥉), Топ-20 списком игроков, фильтром «Друзья / Все» и просмотром профиля любого игрока.

2. **Задания и Дорога прогресса в нижней панели навигации (`#scr-progress`):**
   - В нижней панели (`#bnav`) раздел «Профиль» заменён на «Задания» (`data-nav="progress"`).
   - Включает в себя:
     - **Дорога прогресса (Trophy / Progress Road):** интерактивная шкала наград по кубкам и уровням (золото, статус «Следопыт», рамка «Изумруд», фигурка «Магистр», «Золотой сундук», чемпионские кубки) с кнопками «Забрать».
     - **Задания:** ежедневные задания, недельные цели с «Большим сундуком недели» (+100 золота), вкладки достижений и коллекций.

3. **Выпуск на боевой сервер в 1 клик (Promote to Production):**
   - **Прямо из приложения (тестовый APK):** в панели основателя (по 7 тапам на номер версии в Настройках) добавлена секция «🚀 Выпустить в боевую версию (Production)» с чекбоксом обязательного обновления и запуском через GitHub REST API прямо с телефона с живым отслеживанием статуса сборки.
   - **Из веб-панели основателя (`tools/founder-admin.html`):** выпуск переведён на прямой вызов GitHub API (`triggerWorkflowDispatch`) по токену GitHub Actions PAT.

4. **Исправленная и надёжная Политика обновлений:**
   - Модуль `src/app/update.js` (`isUpdateMandatory`, `shouldPromptUpdate`): корректно сравнивает `currentCode < minRequiredCode`.
   - Нативный загрузчик Android `Updater.java`: считывает `mandatory` и `minRequiredCode` напрямую из `latest.json`.
   - В воркфлоу `promote-production.yml`: скрипт `scripts/ci/make-latest-json.py` генерирует `latest.json` с учётом флага `mandatory` и порога `minRequiredCode`.

5. **Выделенный личный профиль игрока (`#scr-profile`):**
   - Открывается по клику на аватарку / никнейм в левом верхнем углу меню (`#mprof`).
   - Очищен от квестов и рейтинга: содержит только личную информацию игрока (аватар, ник, статус, уровень с кольцом опыта, рюкзак «🎒 Мои предметы», статистика винрейта, мастерство по режимам, постройки и вход/выход).

6. **Уведомления (тосты):**
   - Плашка уведомлений (`.tile-toast, .note`) смещена вниз (`top: max(64px, ...)`) и уменьшена в размерах, чтобы гарантированно не перекрывать кнопки шапки и верхний интерфейс.
   - Внутриигровой тост `.toast` смещён на `top: 60px` с `pointer-events: none`.

7. **Кнопка «Сыграть с ботами» внизу экранов:**
   - Лишняя кнопка убрана из экрана правил и нигде внизу экранов не дублируется.

## 2. Архитектура проекта и ключевые файлы

| Файл / Директория | Назначение |
|---|---|
| `web/game.html` | Основная разметка, игровые экраны (`#scr-menu`, `#scr-profile`, `#scr-progress`, `#scr-rating`, `#scr-shop`, `#scr-friends`, `#scr-rules`, `#scr-game`), обработчики и UI-логика. |
| `src/ui/styles.css` | Основные стили игры, включая адаптивные стили мобильного приложения, анимации плиток, сундуков, дороги прогресса, навигации. |
| `src/engine/` | Игровой движок плиточной стратегии: правила (`board.js`), генерация плиток (`tiles.js`), подсчёт очков (`scoring.js`), ИИ ботов с 3 уровнями сложности и архетипами (`bots.js`). |
| `src/account/auth.js` | Авторизация, генерация разнообразных мультиязычных никнеймов (геймертаги, тотемы, титулы). |
| `src/state/` | Состояние игры: прогресс, ежедневные и недельные задания (`progress.js`), каталог фигурок, рамок и сундуков (`catalog.js`), сохранение матчей (`save.js`). |
| `src/app/update.js` | Логика обновления приложения: проверка версий, порог обязательности `isUpdateMandatory`, пауза партии при обновлении. |
| `src/ui/inbox.js` | Центр уведомлений и наград («Статус Олд», промокоды, подарки). |
| `app/build.gradle` | Сборка Android: флейворы `staging` (`app.crownfall.tiletopia.test`) и `github` / `play` (`app.crownfall.tiletopia`). |
| `app/src/staging/java/.../Updater.java` | Клиент авто-обновления для тестовой версии: проверяет `staging-latest/latest-staging.json` и устанавливает апдейты поверх установленного приложения. |
| `.github/workflows/staging.yml` | Непрерывная сборка тестового APK при каждом пуше в `main` и `dev/**` с авто-инкрементом versionCode и публикацией в релиз `staging-latest`. |
| `.github/workflows/promote-production.yml` | Публикация боевого релиза в один клик с поддержкой mandatory-флага и minRequiredCode. |
| `tools/founder-admin.html` | Панель основателя: мониторинг тестовой сборки, список невыпущенных коммитов (`prodTag...main`), управление релизами, политика обновлений. |

## 3. Правила разработки и ревью для Claude

1. **Тесты перед коммитом:**
   Всегда проверяй: `node --test tests/*.test.cjs`. Все 213 тестов обязаны проходить.
2. **Сборка веб-ресурсов для Android:**
   После редактирования `web/game.html` или стилей обязательно запускай:
   ```bash
   sh scripts/wrap-web.sh
   sh scripts/wrap-web.sh web
   ```
   Это генерирует `app/src/main/assets/index.html` и веб-версию.
3. **Авторство коммитов:**
   `crownfall <crownfall90@gmail.com>`
4. **Синхронизация веток:**
   Изменения пушатся в `main`, затем вливаются в `dev/test-features` (чтобы запускался CI для обеих веток).
